# Study Psychology & Social Science

A web-based interactive study aid for psychology students. This application provides multiple-choice quizzes and fill-in-the-blank exercises organized by chapters, helping students test their knowledge of psychology concepts.

## Features

- **Multiple Choice Quiz**: Test your knowledge with questions from various psychology chapters
- **Fill-in-the-Blank Exercises**: Practice completing psychological statements and definitions
- **Chapter Selection**: Focus your study on specific topics or chapters
- **Instant Feedback**: Get immediate feedback on your answers
- **Progress Tracking**: Monitor your performance while studying
- **Celebration Animation**: Experience a confetti celebration when you complete a quiz successfully

## Getting Started

### Prerequisites

This is a web-based application that runs directly in the browser. No installation is required.

### Usage

1. Open `index.html` in your web browser to start the multiple-choice quiz
2. Use the chapter dropdown to select a specific topic
3. Answer the questions by clicking on your chosen option
4. Click "Submit" when you've answered all questions to see your results
5. Navigate to "Fill in" to practice with fill-in-the-blank exercises

## Project Structure

- `index.html`: Main quiz interface with multiple-choice questions
- `html/fillin.html`: Fill-in-the-blank exercises interface
- `html/about.html`: Information about the project and resources
- `css/style.css`: Styling for the application
- `json/data.json`: Multiple-choice questions and answers database
- `json/fillindata.json`: Fill-in-the-blank questions database
- `libs/`: JavaScript libraries (React, Babel)
- `img/`: Images used in the application
